# TechTalent Website

This repository contains the static build of the TechTalent website, deployed to GitHub Pages. The site is automatically updated through a GitHub Actions workflow from the main repository.

## About

TechTalent bridges the gap between top-tier tech professionals and leading companies in Israel and beyond. Visit our site to learn more about our services, view job postings, or apply to join our talent pool.

## Deployment Information

This repository is the deployment target for GitHub Pages. The actual source code is maintained in a separate repository. When changes are made to the source repository, they are automatically built and deployed here.

## Pages URL

The site is available at: https://talamitay.github.io/techtalent-website-public/
